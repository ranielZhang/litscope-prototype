# LitScope 知研网页原型

这是一个可直接打开的学术文献智能检索网页原型，主入口为 `index.html`。

## 本地预览

双击 `index.html` 即可预览，也可以在项目目录运行：

```bash
npm run build
```

## GitHub Pages

本仓库的 Pages 已配置为由 `main` 分支根目录直接发布，推送后自动更新，页面地址为：

https://ranielzhang.github.io/litscope-prototype/

页面中的检索、筛选、收藏、导出、API 设置和连接测试均为演示交互，连接测试不会发送真实密钥或请求。
